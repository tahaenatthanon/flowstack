## ADDED Requirements

### Requirement: แท็บภาพรวมแสดงการ์ดผู้ติดตามและเข้าชมเพจ
แท็บ "ภาพรวม" SHALL แสดงการ์ด 2 ใบจากข้อมูล `facebook_page_insights_daily` คือ "ผู้ติดตาม" (ยอด `page_follows` ล่าสุด พร้อมผลต่างเทียบ 28 วันก่อน) และ "เข้าชมเพจ" (ผลรวม `page_views_total` 28 วันล่าสุด) ช่วงเวลาของการ์ดคงที่ที่ 28 วันล่าสุด (มีป้ายกำกับ "28 วันล่าสุด") ไม่ผูกกับตัวเลือกช่วงเวลาของ widget อื่นในแท็บ ข้อมูลของการ์ดนี้ SHALL มาจาก `?action=overview` ฟิลด์ `page_summary` (`has_data`, `followers`, `followers_change`, `page_views`)

#### Scenario: แสดง 2 การ์ด
- **WHEN** แท็บ "ภาพรวม" โหลดและ `page_summary.has_data` = true
- **THEN** แสดงการ์ด "ผู้ติดตาม" และ "เข้าชมเพจ" พร้อมป้าย "28 วันล่าสุด"

#### Scenario: ยังไม่มีข้อมูลเพจ
- **WHEN** `page_summary.has_data` = false
- **THEN** ทั้ง 2 การ์ดแสดง "—" แทนค่าตัวเลข

#### Scenario: ไม่ผูกกับตัวเลือกช่วงเวลาอื่น
- **WHEN** ผู้ใช้เปลี่ยนตัวเลือกช่วงเวลาของกราฟแนวโน้ม Engagement หรือของตารางประสิทธิภาพแต่ละแพลตฟอร์ม
- **THEN** ค่าในการ์ดทั้ง 2 ใบไม่เปลี่ยน
