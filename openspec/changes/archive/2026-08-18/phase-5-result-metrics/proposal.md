## Why

หลังเฟส 0 แก้บั๊กบันทึกผลเผยแพร่แล้ว `content_items` มี `published_at` และ `approved_at` เป็นวัตถุดิบครบ แต่แดชบอร์ดคอนเทนต์ยังไม่มีเมตริก "ผลลัพธ์" จริง ๆ — การ์ดบนแท็บวิเคราะห์ยังเป็น "ยอดวิวรวม/ยอดไลก์รวม" ซึ่งทุกแถวเป็น 0 (ยังไม่มีกลไก sync ข้อมูล engagement จนกว่าจะถึงเฟส 2) จึงแสดง 0 ตลอดเหมือนมีผลลัพธ์ ทั้งที่ยังไม่มีข้อมูล นอกจากนี้ระบบยังไม่สามารถตอบคำถามพื้นฐานของผู้จัดการคอนเทนต์ได้ว่า "ผลิตแต่ละชิ้นใช้เวลานานแค่ไหน" และ "ความถี่การโพสต์เป็นไปตามเป้าหมายหรือไม่"

## What Changes

- เพิ่มเมตริกผลลัพธ์ 2 ตัวที่คำนวณจากข้อมูลจริงของระบบ (ไม่พึ่ง credentials ภายนอก):
  - **เวลาผลิตต่อชิ้น** = ค่าเฉลี่ยระยะเวลา `created_at` → `approved_at` ของเนื้อหาที่อนุมัติแล้ว
  - **ความถี่การเผยแพร่** = จำนวนโพสต์/สัปดาห์ นับจาก `published_at` เทียบกับเป้าหมายใน `content_global_settings`
- เพิ่มคอลัมน์เป้าหมายความถี่รายสัปดาห์ (เช่น `weekly_posts_target`) ใน `content_global_settings` (migration) เพื่อให้ผู้ใช้ตั้งเป้าหมายได้
- เพิ่ม endpoint คำนวณเมตริกผลลัพธ์ (backend) คืนค่าสำหรับการ์ดผลลัพธ์
- เพิ่มการ์ดเมตริกผลลัพธ์บนแดชบอร์ดคอนเทนต์ แสดงเวลาผลิตเฉลี่ย และความถี่การโพสต์เทียบเป้าหมาย
- **ซ่อน** การ์ด "ยอดวิวรวม/ยอดไลก์รวม" เมื่อไม่มีข้อมูล engagement จริง (views/likes เป็น 0 ทั้งหมด) แทนที่จะแสดง 0 เป็นผลลัพธ์

## Capabilities

### New Capabilities

- `content-result-metrics`: เมตริกผลลัพธ์การผลิตคอนเทนต์ — คำนวณเวลาผลิตเฉลี่ย (lead time `created_at` → `approved_at`) และความถี่การเผยแพร่ (โพสต์/สัปดาห์จาก `published_at`) เทียบกับเป้าหมายที่ตั้งได้ใน `content_global_settings` พร้อม endpoint และการ์ดแสดงผลบนแดชบอร์ด

### Modified Capabilities

- `content-dashboard-stats`: เปลี่ยนพฤติกรรมการ์ด "ยอดวิวรวม/ยอดไลก์รวม" จาก "แสดง 0 เมื่อไม่มีข้อมูล" เป็น "ซ่อนการ์ดเมื่อไม่มีข้อมูล engagement" เพื่อไม่ให้แสดง 0 เป็นผลลัพธ์ปลอม

## Impact

- `api/brand-content.php` — เพิ่ม `?action=result-metrics` (คำนวณเวลาผลิตเฉลี่ย + ความถี่/สัปดาห์ เทียบเป้าหมาย) และรองรับการอ่าน/เขียน `weekly_posts_target` ผ่าน `?action=global-settings`
- `database/migrations/` — migration ใหม่ 1 ไฟล์ เพิ่มคอลัมน์เป้าหมายความถี่รายสัปดาห์ใน `content_global_settings`
- `src/hooks/useContent.ts` — เพิ่ม hook `useResultMetrics()` และ type ที่เกี่ยวข้อง
- `src/pages/ContentDashboardPage.tsx` — เพิ่มการ์ดเมตริกผลลัพธ์ และซ่อนการ์ดวิว/ไลก์เมื่อไม่มีข้อมูล
- `src/components/content/types.ts` — เพิ่ม type ของ payload เมตริกผลลัพธ์ (ถ้าจำเป็น)
- อาศัยคอลัมน์ `approved_at`/`published_at` ที่เฟส 0 เพิ่มไว้แล้ว — ไม่ต้อง migration คอลัมน์ใหม่บน `content_items`
