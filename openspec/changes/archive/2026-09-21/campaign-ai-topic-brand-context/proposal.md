## Why

การสร้าง/วางแผนแคมเปญด้วย AI ในปัจจุบันผูกอยู่กับการ "เลือกสินค้า" จาก product catalog เป็นแหล่งไอเดียหลักเพียงทางเดียว — โดยเฉพาะ "AI วางแผนแคมเปญ" (batch) ที่บังคับเลือกสินค้าเสมอ (ปุ่มถูก disable ถ้าไม่เลือก) ทำให้สร้างแคมเปญประเภทที่ไม่ผูกกับสินค้าใดสินค้าหนึ่งไม่ได้เลย (เช่น ประกาศทั่วไป, ทักทายเทศกาล, อัปเดตบริษัท, เชิญงาน, ขอบคุณลูกค้า) นอกจากนี้ AI ยังไม่มีบริบทเกี่ยวกับตัวบริษัท/แบรนด์เลยเมื่อไม่ได้เลือกสินค้า ทั้งที่ระบบมีข้อมูลนี้อยู่แล้ว (`brand_contexts` ที่โมดูล Content ใช้อยู่) แต่ฝั่งแคมเปญอีเมลไม่เคยดึงมาใช้

## What Changes

- เพิ่มช่องพิมพ์ไอเดีย/ธีมอิสระใน "AI วางแผนแคมเปญ" (batch) — ผู้ใช้ระบุแนวคิดหลักของทั้งชุดแคมเปญได้โดยไม่ต้องผูกกับสินค้า
- ปรับ "สร้างแคมเปญเดี่ยว" ให้ label/placeholder ของ "หัวข้ออีเมล" สื่อชัดว่าพิมพ์เป็นไอเดียหลวมๆ ได้ ไม่จำเป็นต้องเป็นประโยคหัวข้อที่สมบูรณ์แล้ว (ใช้ field เดิม ไม่เพิ่ม UI ใหม่)
- ยกเลิกเงื่อนไขบังคับเลือกสินค้าในทั้งสองจุด — เปลี่ยนเป็น "ต้องมีอย่างน้อยหนึ่งใน {สินค้า, ไอเดียที่พิมพ์, เปิดใช้ brand context}"
- เมื่อมีทั้งไอเดียที่พิมพ์และสินค้าที่เลือกพร้อมกัน ให้ไอเดียเป็นตัวกำหนดทิศทางหลัก สินค้าเป็นข้อมูลเสริมประกอบ (ไม่ override กัน)
- เพิ่ม checkbox "ใช้ข้อมูลแบรนด์" ในทั้งสองจุด (สร้างแคมเปญเดี่ยว และ AI วางแผนแคมเปญ) — เมื่อติ๊ก ระบบดึงเนื้อหาจาก `brand_contexts` (เฉพาะ `file_type='brand_md'` เท่านั้น ไม่ใช้ `sop_md`) มาเป็นบริบทพื้นฐานให้ AI เสมอ
- เมื่อติ๊กใช้ brand context แล้ว ไม่บังคับต้องมีสินค้า/ไอเดียอีกต่อไป (brand context เพียงพอเป็นฐานให้ generate ได้)

## Capabilities

### New Capabilities
- `campaign-ai-brand-context`: กลไกดึงข้อมูลแบรนด์ (`brand_contexts`, เฉพาะ `brand_md`) มาเป็นบริบทพื้นฐานให้ AI เมื่อผู้ใช้เปิดใช้งาน ใช้ร่วมกันทั้งจุด generate เดี่ยวและ batch

### Modified Capabilities
- `campaign-ai-content-generation`: เปลี่ยนเงื่อนไข "ต้องเลือกสินค้าหรือไม่ก็ได้" ให้ชัดว่ารวมกับไอเดียที่พิมพ์และ brand context ได้ (มีอย่างน้อยหนึ่งอย่าง), กำหนดลำดับความสำคัญเมื่อมีทั้งไอเดียและสินค้าพร้อมกัน, ปรับ label ช่องหัวข้ออีเมลให้สื่อว่าใช้เป็นไอเดียอิสระได้
- `campaign-ai-batch-planning`: ยกเลิกการบังคับเลือกสินค้าเป็นเงื่อนไขเดียว เปลี่ยนเป็นต้องมีอย่างน้อยหนึ่งใน {สินค้า, ไอเดีย/ธีมที่พิมพ์, brand context}, เพิ่ม input ไอเดีย/ธีมของชุดแคมเปญ

## Impact

- `src/components/campaigns/AICampaignPlanDialog.tsx` — เพิ่มช่องไอเดีย/ธีม, checkbox brand context, แก้ validation ปุ่ม "สร้างแผน"
- `src/pages/CampaignsPage.tsx` — แก้ label/placeholder หัวข้ออีเมลในบริบท AI panel, เพิ่ม checkbox brand context, แก้ validation ปุ่ม "สร้าง"
- `api/lib/campaign-ai-prompt.php` — เพิ่ม section brand context ใน system prompt, ปรับ logic รวมไอเดีย+สินค้า
- `api/email-campaigns.php` — `generateCampaignContent()`/`aiPlanCampaigns()` ดึง `brand_contexts` (เมื่อเปิดใช้), แก้ validation เงื่อนไขขั้นต่ำ (ตัด `กรุณาเลือกสินค้า` แบบเดิมออก)
- ไม่มี migration ฐานข้อมูลใหม่ (`brand_contexts` มีอยู่แล้ว, ใช้แค่ query เพิ่ม)
