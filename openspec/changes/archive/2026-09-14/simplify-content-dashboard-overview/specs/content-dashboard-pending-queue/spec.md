## REMOVED Requirements

### Requirement: แสดงคิวรออนุมัติ
**Reason**: การ์ดรายชื่อ "คิวรออนุมัติ" ซ้ำกับตัวเลข "รออนุมัติ" ที่แสดงอยู่แล้วในการ์ด "ความคืบหน้าการผลิต" — สำหรับหน้าภาพรวมที่เน้นให้ผู้อนุมัติเห็นสัดส่วนสถานะอย่างรวดเร็ว รายชื่อรายละเอียดไปดูที่หน้ารายการอนุมัติโดยตรงแทน
**Migration**: จำนวนรออนุมัติยังเห็นได้จากแถบสัดส่วนในการ์ด "ความคืบหน้าการผลิต" (`content-dashboard-work-progress`); รายชื่อรายละเอียดไปที่ `/content?tab=approval` โดยตรง

### Requirement: ใช้ Button จาก Design System
**Reason**: widget ที่ requirement นี้อ้างอิงถูกลบตามเหตุผลข้างต้น
**Migration**: ไม่มีการ์ดคิวรออนุมัติแยกให้ต้องมีปุ่มลัดอีกต่อไปในแท็บภาพรวม
