## MODIFIED Requirements

### Requirement: เนื้อหาที่ตั้งค่าจาก Template ต้องไม่ถูกแก้ไขเพิ่มเติมโดยอัตโนมัติ
เมื่อเลือก template แล้วเนื้อหาอีเมล (`campaignBody`) ถูกตั้งค่าเป็น HTML ของ template นั้น ระบบ SHALL คงเนื้อหานั้นไว้ตรงตามต้นฉบับ (ไม่มีการแก้ไข/ตัดทอนสไตล์เพิ่มเติมโดยอัตโนมัติ) จนกว่าผู้ใช้จะแก้ไขเนื้อหาเองจริงๆ ผ่านการพิมพ์ในตัวแก้ไข

#### Scenario: เนื้อหายังตรงกับ template หลังเลือกโดยไม่ได้แก้ไขอะไร
- **WHEN** ผู้ใช้เลือก template ที่มีสไตล์กำหนดเอง (เช่น สีพื้นหลัง) แล้วไม่ได้พิมพ์แก้ไขอะไรต่อ
- **THEN** เนื้อหาอีเมล (`campaignBody`) ที่จะถูกบันทึกหรือส่งยังคงมีสไตล์ครบตามต้นฉบับของ template นั้น ไม่ถูกตัดทอนออกไป

#### Scenario: แท็บตัวอย่างแสดงตรงกับ template ที่เลือก โดยไม่มี header/footer ซ้อนกัน
- **WHEN** ผู้ใช้เลือก template แล้วเปิดแท็บ "ตัวอย่าง" ของไดอะล็อกสร้าง/แก้ไขแคมเปญ
- **THEN** ตัวอย่างที่แสดงตรงกับรูปแบบของ template นั้นตามที่เห็นในแท็บ Template (สีพื้นหลังและสไตล์อื่นๆ ครบถ้วน) และแสดง header/footer ของ template เพียงชุดเดียวเท่านั้น — ไม่มี header/footer เพิ่มเติมจาก preview wrapper มาครอบซ้อนกับ header/footer ที่ template นั้นมีอยู่แล้วในตัว

#### Scenario: เนื้อหาที่พิมพ์เองแบบไม่ใช่ template ยังคงมี preview header/footer ตามปกติ
- **WHEN** ผู้ใช้พิมพ์เนื้อหาเองในแท็บ "แก้ไข" โดยไม่ได้เลือก template ใดๆ (เนื้อหาเป็น fragment ธรรมดา ไม่ใช่เอกสาร HTML เต็ม) แล้วเปิดแท็บ "ตัวอย่าง"
- **THEN** แท็บ "ตัวอย่าง" ยังคงแสดง header (ชื่อบริษัท) และ footer (ข้อความยินยอมรับอีเมล) ที่สร้างจาก preview wrapper ตามปกติ เพื่อให้เห็นภาพรวมอีเมลที่จะถูกส่งจริงครบถ้วน
