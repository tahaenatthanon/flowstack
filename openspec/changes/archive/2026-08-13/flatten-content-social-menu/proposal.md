## Why

เมนู "คอนเทนต์โซเชียล" ในกลุ่มการตลาดปัจจุบันใช้โครงสร้าง 3 ระดับ (Group → SubGroup → Items) โดยมี sub-menu ซ้อนอยู่ 3 รายการ (แดชบอร์ด, ผลงานคอนเทนต์, ปฏิทินคอนเทนต์) ทำให้การเข้าถึงหน้าเหล่านี้ต้องคลิก 2 ครั้ง และ "ผลงานคอนเทนต์" ซึ่งเป็นหน้าหลักที่ใช้บ่อยกลับถูกซ่อนอยู่ใต้เมนูย่อย ทั้งที่เมนูคอนเทนต์ทั้งหมดควรอยู่ในระดับเดียวกับรายการอื่นในกลุ่มการตลาดเพื่อให้เข้าถึงได้รวดเร็วขึ้น

## What Changes

- ย้าย sub-menu ภายใต้ "คอนเทนต์โซเชียล" (แดชบอร์ด, ผลงานคอนเทนต์, ปฏิทินคอนเทนต์) ออกมาเป็นเมนูหลักระดับเดียวกับรายการอื่นในกลุ่มการตลาด
- นำ "คอนเทนต์โซเชียล" (`/content`) มาเป็นชื่อเมนูของหน้ารายการเนื้อหา (เดิมชื่อ "ผลงานคอนเทนต์") ในตำแหน่งหลัง "แคมเปญอีเมล" โดยใช้ไอคอน `PenTool` เดิม
- ใช้ "แดชบอร์ดคอนเทนต์" (`/content-dashboard`) และ "ปฏิทินคอนเทนต์" (`/content-planner`) เป็นรายการตรงในกลุ่มการตลาด โดยคง `menuKey` เดิมเป็น `marketing`
- จัด "แดชบอร์ดคอนเทนต์" (`/content-dashboard`) ไว้เป็นรายการแรกสุด (บนสุด) ของกลุ่มการตลาด เพื่อให้ผู้ใช้เข้าถึงภาพรวมของระบบได้ง่ายขึ้น
- **BREAKING**: โครงสร้างเมนูการตลาดเปลี่ยนจาก 3 ระดับ (มี sub-group "คอนเทนต์โซเชียล") เป็น 2 ระดับแบบแบนราบ — ไม่มี sub-group "คอนเทนต์โซเชียล" อีกต่อไป
- คงรูปแบบ UI ตาม Design System เดิม (ใช้ `NavItem` แบบแบนราบ, shadcn-ui, ไอคอน lucide-react เดิม) — ไม่สร้าง component UI ใหม่

## Capabilities

### New Capabilities

_(ไม่มี — ไม่มีการเพิ่ม capability ใหม่)_

### Modified Capabilities

- `sidebar-nested-menu`: เปลี่ยน requirement "Marketing menu restructured with children items" — กลุ่มการตลาดไม่ใช้ sub-group "คอนเทนต์โซเชียล" อีกต่อไป แต่แสดงรายการคอนเทนต์เป็นเมนูหลักแบบแบนราบ (คอนเทนต์โซเชียล, แดชบอร์ดคอนเทนต์, ปฏิทินคอนเทนต์)

## Impact

- `src/components/AppSidebar.tsx` — แก้ไข `NAV_GROUPS` กลุ่ม `marketing`: ลบ item "คอนเทนต์โซเชียล" ที่มี `children` ออก และเพิ่ม "คอนเทนต์โซเชียล", "แดชบอร์ดคอนเทนต์", "ปฏิทินคอนเทนต์" เป็นรายการตรงใน `items` โดยเรียง "แดชบอร์ดคอนเทนต์" ไว้บนสุด
- ไม่มีการเปลี่ยนแปลง route, API, database หรือ permission (`menuKey` ยังคงเป็น `marketing` เหมือนเดิม)
- `NestedNavItem` และ `children?: NavItem[]` ใน `AppSidebar.tsx` ยังคงเก็บไว้ (ไม่ถูกใช้งานแล้ว แต่ยังไม่ลบใน scope นี้ — อาจใช้ในอนาคต)
