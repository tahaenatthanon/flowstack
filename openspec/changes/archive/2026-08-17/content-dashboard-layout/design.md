## Context

หน้า `ContentDashboardPage` (แดชบอร์ดคอนเทนต์) ปัจจุบันจัดเลย์เอาต์เป็น master grid 2 คอลัมน์บนจอ `xl` (`xl:grid-cols-3`, ซ้าย `xl:col-span-2` ขวา `1/3`) โดย:

- **คอลัมน์ซ้าย** มี 2 Card: "ภาพรวมสถานะคอนเทนต์" (Work Progress) และ Card ที่ใช้ `Tabs` ระหว่าง "เนื้อหายอดนิยม" (default) กับ "เนื้อหาล่าสุด"
- **คอลัมน์ขวา** มี 4 Card: "รออนุมัติ", "กำหนดการโพสต์ถัดไป", "แพลตฟอร์ม", "สถานะช่องทาง"

ปัญหา: widget "เนื้อหายอดนิยม" ไม่ถูกใช้งานคุ้มค่า และ Card แบบ `Tabs` ทำให้คอลัมน์ซ้ายสูงกว่าคอลัมน์ขวา เลย์เอาต์โดยรวมไม่สมดุล

## Goals / Non-Goals

**Goals:**
- ลบ "เนื้อหายอดนิยม" ออกจากแดชบอร์ดคอนเทนต์ทั้งหมด
- ให้ "เนื้อหาล่าสุด" เป็นตารางหลักใน Card เดียว (ไม่มี `Tabs`)
- จัดระยะและขนาด Column ของตาราง "เนื้อหาล่าสุด" ให้สอดคล้องกับความกว้างคอลัมน์ซ้าย (2/3)
- ปรับให้ Section ฝั่งซ้ายและขวา มีระยะห่างแนวตั้งและขนาดที่สมดุลเป็นระเบียบ

**Non-Goals:**
- ไม่แก้ logic การดึงข้อมูล (data fetching) หรือ endpoint ใด ๆ
- ไม่เพิ่ม widget/ข้อมูลใหม่
- ไม่เปลี่ยนเลย์เอาต์ของ Stat cards หรือ header

## Decisions

### 1. ลบ widget "เนื้อหายอดนิยม" โดยตรง
- ลบตัวแปร `topContent` และ block `TabsContent value="top"` ออกทั้งหมด
- ลบอิมพอร์ต `Tabs`, `TabsContent`, `TabsList`, `TabsTrigger` และ icon `TrendingUp` (ถ้าไม่ถูกใช้ที่อื่นในไฟล์)
- **Rationale**: การลบโดยตรงชัดเจนและลด dead code มากกว่าการซ่อนด้วย CSS
- **Alternative considered**: ซ่อนแท็บด้วย CSS — ปฏิเสธเพราะเหลือ code ตายและ state `Tabs` ที่ไม่จำเป็น

### 2. แทนที่ Card `Tabs` ด้วย Card เดียว "เนื้อหาล่าสุด"
- โครงสร้างใหม่: `<Card>` + `<CardHeader>` (title "เนื้อหาล่าสุด") + `<CardContent className="p-0">` + `<Table>` ของ `recentItems`
- นำตารางเดิมจาก `TabsContent value="recent"` มาใช้โดยตรง
- **Rationale**: รักษา consistency กับ Card อื่นที่ใช้ `CardHeader`/`CardContent`

### 3. ปรับ Column ของตาราง "เนื้อหาล่าสุด"
- คงคอลัมน์: ชื่อ (ขยายตามพื้นที่, `truncate`), ประเภท (ซ่อนต่ำกว่า `sm`), แพลตฟอร์ม (ซ่อนต่ำกว่า `md`), สถานะ
- เพิ่ม `min-w`/`truncate` กับคอลัมน์ชื่อให้รับความกว้าง 2/3 ได้พอดี โดยไม่ดันตารางล้น
- **Rationale**: คอลัมน์ซ้ายกว้าง 2/3 จึงให้คอลัมน์ "ชื่อ" ขยายตัวได้เต็มที่ ส่วนคอลัมน์อื่นคงความกว้างตายตัว

### 4. สมดุล Section ซ้าย–ขวา
- ทั้งสองคอลัมน์ใช้ `space-y-6` อย่างสม่ำเสมอ (คงเดิม)
- Card ภายในใช้ `CardHeader className="pb-2"` + `CardTitle className="text-sm font-medium"` เหมือนกันทุกใบ เพื่อให้ความสูงหัว Card เท่ากัน
- ใช้ระยะ padding ของ `CardContent` ที่สม่ำเสมอระหว่างสองฝั่ง
- **Rationale**: ทำให้ขอบบน/ล่างของแถว Card ทั้งสองฝั่ง align กันและดูเป็นระเบียบ

## Risks / Trade-offs

- [การลบ `topContent` อาจกระทบถ้ามีการ import/usage อื่น] → ตรวจสอบด้วย `grep` ทั้งโปรเจกต์ก่อนลบ; สิ่งนี้ scoped เฉพาะไฟล์นี้
- [ตาราง "เนื้อหาล่าสุด" อาจล้นถ้าชื่อยาว] → ใช้ `truncate` + `max-w` ตามเดิม และให้คอลัมน์ "ชื่อ" รับพื้นที่เหลือ
- [การปรับสมดุลอาจดูต่างไปตามข้อมูลจริง] → ใช้ spacing token เดิม (`space-y-6`, `pb-2`) เพื่อรักษา design system เดิม
