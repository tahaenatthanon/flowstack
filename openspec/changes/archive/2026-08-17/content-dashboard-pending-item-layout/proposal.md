## Why

แดชบอร์ดคอนเทนต์มี 2 จุดที่ควรปรับ: (1) widget "รออนุมัติ" มีปุ่ม "ดูรายการอนุมัติทั้งหมด" ด้านล่างซ้ำซ้อนกับปุ่ม "ดูทั้งหมด" ที่หัว Card จึงควรลบออก และคงรูปแบบรายการเดิม; (2) widget "เนื้อหาล่าสุด" แสดงเป็นตารางที่ดูข้อมูลไม่หนาแน่นเท่า list จึงควรปรับเป็นรูปแบบ list หลายบรรทัดที่แสดงรูปภาพ ข้อมูลประเภท/แพลตฟอร์ม/สถานะ/วันที่ได้ครบถ้วนและเป็นระเบียบ

## What Changes

- ลบปุ่ม "ดูรายการอนุมัติทั้งหมด" (ปุ่มเต็มความกว้างที่ด้านล่าง) ออกจาก Card "รออนุมัติ" (คงเหลือปุ่ม "ดูทั้งหมด" ที่มุมขวาบนหัว Card)
- "รออนุมัติ": คงรูปแบบการแสดงผลเดิมของแต่ละรายการ (ชื่อเนื้อหา + วันที่สร้าง) — ไม่ปรับ layout
- "เนื้อหาล่าสุด": ปรับจากตารางเป็นรูปแบบ list หลายบรรทัด โดยแต่ละรายการมีรูปภาพทางซ้าย และข้อมูลทางขวาจัดเรียงเป็นบรรทัด:
  - บรรทัด 1: ชื่อเนื้อหา
  - บรรทัด 2: ประเภท (`TYPE_MAP`) | แพลตฟอร์ม (`PLATFORM_MAP`)
  - บรรทัด 3: สถานะ (`STATUS_MAP`) | วันที่สร้าง
- ปรับขนาดรูปภาพให้มีความสูงเท่ากับพื้นที่ข้อมูลด้านข้างทั้งหมด และจัดแนวให้สอดคล้องกันทุกแถว

### Modified Capabilities

- `content-dashboard-pending-queue`: เปลี่ยนข้อกำหนดของ widget "รออนุมัติ" — ลบปุ่มล่าง และคงรูปแบบการแสดงผลเดิมของรายการ (ชื่อ + วันที่สร้าง)
- `content-dashboard-layout`: เปลี่ยนข้อกำหนดของ "เนื้อหาล่าสุด" — จากตารางเป็น list หลายบรรทัด (รูปภาพ + ชื่อ / ประเภท|แพลตฟอร์ม / สถานะ|วันที่) และปรับขนาด/แนวของรูปภาพให้สอดคล้องกันทุกแถว

## Impact

- `src/pages/ContentDashboardPage.tsx`: ไฟล์หลักที่ถูกแก้ (Card "รออนุมัติ" และ Card "เนื้อหาล่าสุด")
- ไม่กระทบ API, database schema, หรือ dependency
- ยังคงใช้ `STATUS_MAP`, `PLATFORM_MAP`, `TYPE_MAP`, `generated_image_url` ที่มีอยู่แล้ว
