## Context

หน้า `ContentDashboardPage` มี 2 ส่วนที่เกี่ยวข้อง:

- **"รออนุมัติ"** (คอลัมน์ขวา): มีปุ่ม ghost "ดูทั้งหมด" ที่หัว Card + แต่ละรายการแสดงชื่อ + วันที่สร้าง (`created_at`) และมีปุ่ม full-width "ดูรายการอนุมัติทั้งหมด" ที่ด้านล่างของ `CardContent` ซึ่งซ้ำซ้อน
- **"เนื้อหาล่าสุด"** (คอลัมน์ซ้าย): ปัจจุบันแสดงเป็น `Table` มีคอลัมน์ thumbnail / ชื่อ / ประเภท / แพลตฟอร์ม / สถานะ

## Goals / Non-Goals

**Goals:**
- "รออนุมัติ": ลบปุ่ม "ดูรายการอนุมัติทั้งหมด" ด้านล่าง และคงรูปแบบการแสดงผลเดิมของแต่ละรายการ (ชื่อ + วันที่สร้าง)
- "เนื้อหาล่าสุด": เปลี่ยนจากตารางเป็น list หลายบรรทัด พร้อมรูปภาพ + ประเภท + แพลตฟอร์ม + สถานะ + วันที่สร้าง
- ปรับรูปภาพให้สูงเท่ากับพื้นที่ข้อมูลด้านข้าง และแนวสอดคล้องกันทุกแถว

**Non-Goals:**
- ไม่แก้ logic การดึงข้อมูล/การ sort
- ไม่เปลี่ยน widget อื่น หรือ Stat cards
- ไม่เปลี่ยนปุ่ม "ดูทั้งหมด" หัว Card ของทั้งสองส่วน

## Decisions

### 1. "รออนุมัติ": ลบปุ่มล่าง + คงรายการเดิม
- ลบปุ่ม full-width "ดูรายการอนุมัติทั้งหมด" ออกจาก `CardContent`
- คงรูปแบบรายการเดิม: `ชื่อ (truncate)` + `วันที่สร้าง (formatDate)` โดยไม่เพิ่ม thumbnail/type/platform/status
- **Rationale**: ปุ่มหัว Card "ดูทั้งหมด" ทำหน้าที่เดียวกันอยู่แล้ว และผู้ใช้ต้องการคงรูปแบบเดิมของรายการ

### 2. "เนื้อหาล่าสุด": เปลี่ยนจาก Table เป็น list หลายบรรทัด
- แทนที่ `<Table>` เดิมด้วย `<div className="space-y-3">` ของรายการ
- ต่อรายการใช้ flex row: รูปภาพซ้าย (`shrink-0`) + ข้อมูลขวา (`flex-1 min-w-0`)
- **Rationale**: list หลายบรรทัดแสดงข้อมูลได้หนาแน่นกว่าในคอลัมน์ซ้าย 2/3 และจัดแนวเป็นระเบียบ

### 3. ข้อมูลขวาจัด 3 บรรทัด
- บรรทัด 1: `ชื่อเนื้อหา` (truncate) บรรทัดเดียว
- บรรทัด 2: Badge ประเภท (`TYPE_MAP`) + Badge/ข้อความแพลตฟอร์ม (`PLATFORM_MAP`) ในบรรทัดเดียวกัน (`flex items-center gap-2`)
- บรรทัด 3: Badge สถานะ (`STATUS_MAP`) + วันที่สร้าง ในบรรทัดเดียวกัน (`flex items-center gap-2`)
- **Rationale**: สอดคล้องกับที่ผู้ใช้ระบุ "ชื่อ", "ประเภท | แพลตฟอร์ม", "สถานะ | วันที่สร้าง" เรียงตามลำดับ โดยประเภทอยู่หน้าแพลตฟอร์ม

### 4. รูปภาพสูงเท่ากับพื้นที่ข้อมูลด้านข้าง
- รูปภาพใช้ `self-stretch` + `h-full` ภายใน flex row เพื่อให้สูงเท่ากับพื้นที่ข้อมูล (3 บรรทัด) โดยใช้ `object-cover`
- กำหนด `min-h` ที่เหมาะสม (เช่น `min-h-[56px]`) เพื่อกันรูป/ไอคอนสั้นเกินไป
- **Rationale**: `self-stretch` ทำให้รูปสูงตามความสูงของคอลัมน์ข้อมูล สอดคล้องทุกแถว

### 5. Fallback รูปภาพ
- ถ้า `generated_image_url` มี → `<img>` แบบ `object-cover`
- ถ้าไม่มี → กล่อง `bg-muted` พร้อมไอคอนตาม `TYPE_MAP[item.type]`
- **Rationale**: คง pattern เดียวกับตาราง "เนื้อหาล่าสุด" เดิม

## Risks / Trade-offs

- [ชื่อยาวอาจดัน Badge ประเภทล้น] → ใช้ `truncate` + `min-w-0` บนชื่อ และให้ Badge `shrink-0`
- [รูปภาพสัดส่วนต่างกันทำให้สูงไม่เท่ากัน] → ใช้ `object-cover` + `self-stretch` เพื่อบังคับให้สูงเท่ากัน
- [ลบ Table อาจกระทบการจัด layout ฝั่งซ้าย] → ใช้ `space-y-3` และคง `flex-1 flex-col` ของ Card เดิมไว้
