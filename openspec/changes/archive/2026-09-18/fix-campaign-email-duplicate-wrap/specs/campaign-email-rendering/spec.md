## ADDED Requirements

### Requirement: แคมเปญที่มาจาก template ต้องบันทึกที่มาของ template ไว้
เมื่อมีการสร้างหรือแก้ไขแคมเปญจากหน้าต่างสร้างแคมเปญ ระบบ SHALL บันทึกไว้ว่าเนื้อหาของแคมเปญนั้นมาจาก template สำเร็จรูปตัวไหน (ถ้ามี) ไว้ในฟิลด์ `email_campaigns.template_id`

#### Scenario: ผู้ใช้เลือก template สำเร็จรูป
- **WHEN** ผู้ใช้เลือก template จากแกลเลอรี template ในหน้าต่างสร้างแคมเปญแล้วบันทึกแคมเปญ
- **THEN** ค่า `template_id` ของแคมเปญถูกบันทึกเป็น id ของ template นั้น

#### Scenario: ผู้ใช้สร้างแคมเปญขึ้นเองตั้งแต่ต้น
- **WHEN** ผู้ใช้สร้างแคมเปญโดยไม่ได้เลือก template ใดจากแกลเลอรีเลย
- **THEN** ค่า `template_id` ของแคมเปญถูกบันทึกเป็น null

#### Scenario: ผู้ใช้ยกเลิกการเลือก template ที่เลือกไว้ก่อนหน้า
- **WHEN** ผู้ใช้คลิก template ที่เลือกไว้แล้วซ้ำอีกครั้งเพื่อยกเลิกการเลือก (เนื้อหาถูกล้างกลับเป็นค่าว่าง) แล้วบันทึกแคมเปญ
- **THEN** ค่า `template_id` ของแคมเปญถูกบันทึกเป็น null

### Requirement: ขั้นตอนการส่งอีเมลต้องไม่ห่อ chrome ซ้ำสำหรับแคมเปญที่มาจาก template
เมื่อส่งอีเมลแคมเปญ ระบบ SHALL NOT ห่อ header/footer แบบทั่วไปเพิ่มเข้าไปในเนื้อหา หากแคมเปญนั้นมีค่า `template_id` ที่ไม่ใช่ null เนื่องจาก body ที่บันทึกไว้มี header และ footer ของ template นั้นอยู่แล้ว

#### Scenario: ส่งแคมเปญที่มาจาก template และถูกแก้ไขภายหลัง
- **WHEN** แคมเปญมีค่า `template_id` ที่ไม่ใช่ null และ `body_html` ของแคมเปญถูกแก้ไขผ่านช่องแก้ไขเนื้อหาหลังจากเลือก template แล้ว (จนไม่มี tag `<html>` หลงเหลืออยู่)
- **THEN** อีเมลที่ส่งถึงผู้รับมี header และ footer อย่างละหนึ่งชุดพอดี — เป็นของ template เดิม โดยไม่มี header/footer แบบทั่วไปถูกเพิ่มเข้ามาอีก

#### Scenario: ส่งแคมเปญที่มาจาก template โดยไม่ได้แก้ไข
- **WHEN** แคมเปญมีค่า `template_id` ที่ไม่ใช่ null และ `body_html` ยังคง HTML document เต็มรูปแบบของ template ไว้ (ยังมี tag `<html>` อยู่)
- **THEN** อีเมลที่ส่งถึงผู้รับถูกส่งออกไปโดยไม่มีการเปลี่ยนแปลง ไม่มีการห่อเพิ่มเติมใดๆ

### Requirement: ขั้นตอนการส่งอีเมลยังคงห่อ chrome ให้แคมเปญที่เขียนขึ้นเองตั้งแต่ต้น
เมื่อส่งอีเมลแคมเปญที่มีค่า `template_id` เป็น null ระบบ SHALL ยังคงห่อ header/footer แบบทั่วไปเพิ่มเข้าไปเหมือนพฤติกรรมปัจจุบัน

#### Scenario: ส่งแคมเปญที่เขียนขึ้นเองตั้งแต่ต้น
- **WHEN** แคมเปญมีค่า `template_id` เป็น null
- **THEN** อีเมลที่ส่งถึงผู้รับมี header แบบทั่วไป (ชื่อบริษัท) และ footer แบบทั่วไป (ชื่อบริษัท + ข้อความแจ้งการสมัครรับข้อมูล) ถูกห่อเพิ่มเข้ามา เหมือนก่อนการแก้ไขครั้งนี้
