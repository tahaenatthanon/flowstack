## Why

Change `pull-content-dialog-filters` (archived) เพิ่มตัวกรอง 3 มิติเข้าไปในหน้าต่าง "ดึงคอนเทนต์" แต่มี 2 จุดที่ layout ผิดพลาดที่พบระหว่างใช้งานจริงหลัง apply:

1. **แถวตัวกรองแยกบรรทัดจาก label ผิดที่** — แถวนอกของตัวกรองแต่ละมิติ (ประเภท/สถานะ/แพลตฟอร์ม) มี `flex-wrap` ซ้อนกับกล่อง pill ข้างในที่มี `flex-wrap` อยู่แล้ว ทำให้ label (เช่น "แพลตฟอร์ม:") ถูกดันแยกไปอยู่คนละบรรทัดกับ pill ทั้งแถว ทั้งที่ pill ข้างในมีกลไกตกบรรทัดของตัวเองเพียงพออยู่แล้ว
2. **Platform badge ของรายการคอนเทนต์ล้นกรอบการ์ด** — บั๊กที่มีอยู่ก่อนหน้า (ไม่เกี่ยวกับ change ก่อนหน้านี้) แถวหัวข้อของการ์ดแต่ละใบ (icon ประเภท + ชื่อเรื่อง + icon ตา + platform badge) ไม่มี `flex-wrap` และ badge ถูกกำหนด `shrink-0` ไว้ พอคอนเทนต์มีหลายแพลตฟอร์มพร้อมกัน (พบจริงถึง 8-11 แพลตฟอร์มในบางรายการ) แถวทั้งแถวดันความกว้างล้นการ์ดแทนที่จะตกบรรทัด
3. **แพลตฟอร์มแสดงชื่อเต็มแทนไอคอนอย่างเดียว** — ทั้งแถวตัวกรองแพลตฟอร์มและ badge บนการ์ดคอนเทนต์ใน `PullFromContentDialog.tsx` แสดงทั้งไอคอน + ชื่อแพลตฟอร์มเต็ม ในขณะที่หน้า "ผลงานคอนเทนต์" (`ContentListTab.tsx`) ซึ่งเป็น pattern มาตรฐานของระบบ ใช้ไอคอนอย่างเดียว (มี `title` เป็น tooltip) ทำให้ไม่สอดคล้องกันและกินพื้นที่แนวนอนโดยไม่จำเป็น

## What Changes

- เอา `flex-wrap` ออกจาก container นอกของแถวตัวกรองทั้ง 3 แถว (ประเภท/สถานะ/แพลตฟอร์ม) ใน `PullFromContentDialog.tsx` — เหลือแค่ `flex items-center gap-1.5` ให้ label คงอยู่บรรทัดเดียวกับ pill แถวแรกเสมอ ส่วน pill ที่ล้นแถวแรกค่อยตกไปบรรทัดถัดไปผ่าน `flex-wrap` ที่มีอยู่แล้วในกล่อง pill ชั้นใน
- ย้าย `PlatformBadgeList` ออกจากแถวหัวข้อของการ์ดคอนเทนต์ในรายการ ไปเป็น `<div>` แยกต่างหากอยู่ใต้แถวหัวข้อ (รูปแบบเดียวกับที่ `ContentCardDialog.tsx` ใช้อยู่แล้วสำหรับบริบทเดียวกัน) — แถวหัวข้อ (icon ประเภท + ชื่อเรื่อง + icon ตา) จึงคงเหลือ 1 บรรทัดเสมอ ไม่ว่าคอนเทนต์จะมีกี่แพลตฟอร์ม
- เปลี่ยนทั้งแถวตัวกรองแพลตฟอร์มและ badge บนการ์ดคอนเทนต์ให้แสดงไอคอนอย่างเดียว (เอาชื่อแพลตฟอร์มออก) พร้อม `title` tooltip บอกชื่อเต็มตอน hover — อ้างอิง pattern เดียวกับหน้า "ผลงานคอนเทนต์" (`ContentListTab.tsx`)

### Modified Capabilities

## Impact

- **Frontend**: `src/components/content/dialogs/PullFromContentDialog.tsx` เท่านั้น (แก้ CSS class/JSX structure ล้วนๆ ไม่มี logic ใหม่)
- **ไม่แตะ**: `content-items.php`, `useContent.ts`, `PlatformBadgeList.tsx`, `ContentListTab.tsx`, `ContentPlannerPage.tsx` และไฟล์อื่นที่ใช้ pattern เดียวกันอยู่แล้ว (ไม่มีบั๊กในจุดนั้น — ใช้เป็นต้นแบบเท่านั้น)
- ไม่มี DB/API เปลี่ยนแปลง — เป็นการแก้ layout/แสดงผลล้วนๆ ย้อนกลับได้ด้วย git revert ไฟล์เดียว
