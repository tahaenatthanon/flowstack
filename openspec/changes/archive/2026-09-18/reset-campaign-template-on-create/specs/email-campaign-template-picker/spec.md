## ADDED Requirements

### Requirement: เปิดไดอะล็อกสร้างแคมเปญใหม่ต้องไม่มี Template ค้างจากแคมเปญก่อนหน้า
เมื่อผู้ใช้เปิดไดอะล็อก "สร้างแคมเปญ" สำหรับสร้างแคมเปญใหม่ (ไม่ใช่การแก้ไขแคมเปญเดิม) ระบบ SHALL ล้างค่า template ที่เลือกไว้ (`selectedTemplate`) กลับเป็นค่าว่างเสมอ ไม่ว่าแคมเปญก่อนหน้าที่สร้าง/แก้ไขไปแล้วจะเลือก template ใดไว้ก็ตาม

#### Scenario: สร้างแคมเปญใหม่หลังบันทึกแคมเปญก่อนหน้าสำเร็จ
- **WHEN** ผู้ใช้สร้างแคมเปญ A โดยเลือก template ใดก็ได้ บันทึกสำเร็จ แล้วกดปุ่ม "สร้างแคมเปญ" อีกครั้งเพื่อสร้างแคมเปญ B
- **THEN** ไดอะล็อกที่เปิดขึ้นสำหรับแคมเปญ B ไม่มี template ใดถูกเลือกไว้ล่วงหน้า (ไม่มีเครื่องหมาย ✓ ติดอยู่ที่ template gallery) และกล่องเนื้อหาอีเมลว่างเปล่าสอดคล้องกัน

#### Scenario: สร้างแคมเปญใหม่ผ่านการดึงคอนเทนต์จากบทความ หลังเคยเลือก template ไว้ก่อนหน้า
- **WHEN** ผู้ใช้เคยเลือก template ไว้ในแคมเปญก่อนหน้า แล้วสร้างแคมเปญใหม่ผ่านการดึงคอนเทนต์จากบทความ (fromContent)
- **THEN** ไดอะล็อกที่เปิดขึ้นไม่มี template จากแคมเปญก่อนหน้าติดค้างอยู่เช่นกัน
