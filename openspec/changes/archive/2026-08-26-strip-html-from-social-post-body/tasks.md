## 1. เพิ่มตัวแปลง HTML เป็นข้อความ

- [x] 1.1 เพิ่มฟังก์ชัน `publish_html_to_text(string $html, string $dupTitle = ''): string` ใน `api/lib/publish-dispatch.php` วางไว้ก่อน `dispatch_content()` — ยังไม่ผูกกับผู้เรียก เพื่อทดลองแยกได้
- [x] 1.2 ในฟังก์ชัน: ถ้า `$html` ว่างหลัง `trim()` ให้คืนสตริงว่างทันที ไม่ต้องทำขั้นตอนถัดไป
- [x] 1.3 ในฟังก์ชัน: ถ้า `$dupTitle` ไม่ว่าง → หา `<h1…>…</h1>` **ตัวแรก** แล้วเทียบข้อความข้างในกับ `$dupTitle` โดย normalize ทั้งสองฝั่ง (`strip_tags` → `html_entity_decode(ENT_QUOTES|ENT_HTML5)` → `trim`) ถ้าตรงให้ลบ element นั้นทั้งก้อนออกจาก `$html` — ถ้าไม่ตรงห้ามลบ
- [x] 1.4 ในฟังก์ชัน: ลบ `<script>…</script>` และ `<style>…</style>` พร้อมเนื้อข้างในด้วย regex (`/is`) — **ต้องอยู่ก่อน** `strip_tags()` เพราะ `strip_tags()` เก็บข้อความข้างในไว้
- [x] 1.5 ในฟังก์ชัน: แปลง `<li…>` → `"\n• "`, `<br>`/`<br/>`/`<br />` → `"\n"`, และแท็กปิดบล็อก `</p>` `</h1>`–`</h6>` `</div>` `</ul>` `</ol>` `</blockquote>` → `"\n\n"` — **ไม่รวม `</li>`** ตามรายการใน design ข้อ 3 เพราะ `<li>` เปิดขึ้นบรรทัดใหม่ให้อยู่แล้ว ถ้าใส่จะได้บรรทัดว่างคั่นทุกหัวข้อย่อย
- [x] 1.6 ในฟังก์ชัน: `strip_tags()` แท็กที่เหลือ แล้วจึง `html_entity_decode($text, ENT_QUOTES | ENT_HTML5, 'UTF-8')` — **ลำดับนี้กลับกันไม่ได้** ตามเหตุผลใน design ข้อ 3 และตรงกับสำนวนที่ `api/lib/seo-checklist.php:199` ใช้อยู่
- [x] 1.7 ในฟังก์ชัน: normalize ปิดท้าย — `\r\n`/`\r` → `\n`, ยุบช่องว่าง/แท็บที่ซ้อนกันในบรรทัดเดียว, ยุบ `\n` ตั้งแต่ 3 ตัวขึ้นไปเหลือ 2, `trim()` หัวท้าย
- [x] 1.8 เขียนคอมเมนต์ไทยเหนือฟังก์ชันระบุว่าใช้กับปลายทางที่รับข้อความล้วนเท่านั้น และระบุเหตุผลของลำดับ strip-ก่อน-decode ตามแบบคอมเมนต์อธิบายเหตุผลที่มีอยู่ในไฟล์นี้แล้ว

## 2. ผูกเข้า dispatch_content()

- [x] 2.1 เพิ่มตัวแปร `$socialBody` ใน `dispatch_content()` หลังบรรทัด `:30` — คงบรรทัด `$body = $art['html'] ?? $content['caption'] ?? '';` ไว้ไม่แตะ เพราะเว็บ/CMS ยังใช้ค่านี้

- [x] 2.3 เปลี่ยน 6 arm ของ `match` ที่ `:47-52` (`facebook`, `instagram`, `tiktok`, `lineoa`, `linkedin`, `twitter`) ให้ส่ง `$socialBody` แทน `$body`
- [x] 2.4 ปล่อย arm `wordpress` (`:53`), `wix` (`:54`), `lotusdomino` (`:55`), `custom` (`:56`) ให้ส่ง `$body` เหมือนเดิมทุกตัว — ห้ามแตะ
- [x] 2.5 เขียนคอมเมนต์ไทยที่จุดประกาศ `$socialBody` ระบุว่าโซเชียลรับข้อความล้วน เว็บ/CMS รับ HTML และระบุว่า `caption` มาก่อนเพราะเขียนไว้สำหรับโซเชียลโดยเฉพาะ
- [x] 2.6 ยืนยันว่าไม่ได้แก้ signature ของ `dispatch_*` ตัวใด และไม่ได้แก้บรรทัด `$title ? "$title\n\n$body" : $body` ในฟังก์ชันใด — grep ยืนยัน 6 จุด (`:255`, `:338`, `:385`, `:425`, `:454`, `:505`) ยังเหมือนเดิม
