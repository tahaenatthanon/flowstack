## 1. AttributionTab.tsx — เปลี่ยนสูตรคำนวณสัดส่วน

- [x] 1.1 ใน `SourceTable` (`src/components/marketing/AttributionTab.tsx`) เปลี่ยน `const maxValue = Math.max(...rows.map(r => r.won_value), 1);` เป็น `const total = rows.reduce((sum, r) => sum + r.won_value, 0) || 1;`
- [x] 1.2 เปลี่ยนสูตร `barPct` จาก `Math.min(100, r.won_value / maxValue * 100)` เป็น `Math.min(100, r.won_value / total * 100)` — ตัด guard `maxValue > 0 ? ... : 0` ออกด้วย เพราะ `total` ไม่มีทางเป็น 0 (มี `|| 1` กันไว้แล้ว)
- [x] 1.3 grep ยืนยันไม่มี `maxValue` เหลือค้างในไฟล์แล้ว
