- [x] 3.2 แสดงตัวเลขเปอร์เซ็นต์ (ปัดเศษเป็นจำนวนเต็มด้วย `Math.round`) จากค่า `barPct` ที่คำนวณอยู่แล้ว เป็นข้อความคู่กับแท่ง (flex row, แท่ง shrink-0 + ตัวเลขต่อท้าย)
- [x] 3.3 ตรวจกรณี `maxValue` เป็นไปได้ที่ทุกแถวมี `won_value = 0` — ยืนยันโดยอ่านโค้ด: fallback `Math.max(...rows.map(r => r.won_value), 1)` ที่มีอยู่แล้วทำให้ `maxValue >= 1` เสมอ ไม่มีทางหารด้วยศูนย์ และ `Math.round(0/maxValue*100)` = 0 แสดง "0%" ถูกต้อง ไม่ต้องแก้โค้ดเพิ่ม
